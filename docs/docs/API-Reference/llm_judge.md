# LLM Judge

Bedrock-backed judge for subjective metrics, with versioned prompt templates and
calibration against human scores.

!!! warning
    Evaluated agent output is untrusted input in every judge prompt. See
    [`SECURITY.md`](https://github.com/awslabs/uaef/blob/main/SECURITY.md).
